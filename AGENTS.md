# Project Instructions

## Technology
- Java 21
- Spring Boot
- Maven
- Oracle
- MongoDB
- Redis
- Kafka
- Vault

## Rules
- Production-ready code only.
- Prefer constructor injection.
- Do not use field injection.
- Do not add unnecessary dependencies.
- Do not modify unrelated modules.
- Preserve module boundaries.
- All infrastructure integrations must be configurable.
- Disabled infrastructure must not create connections.
- Configuration must support environment variables/secrets.
- Run Maven tests after changes.
